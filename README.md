# YarnOrbit

YarnOrbit is a highly scalable Cluster Framework for Distributed Applications, managing auto-scaling container orchestration.

With YarnOrbit, you get a lightweight tool that stays out of your way.

**What you get**

- YarnOrbit is a highly scalable
- Cluster Framework for Distributed Applications,
- managing auto-scaling container orchestration

- python

- Pytest for testing

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/YarnOrbit.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

YarnOrbit is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
